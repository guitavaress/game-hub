# Ideias

A caixa de entrada das ideias do Game Hub. **Ideia aqui não é tarefa:** nenhum agente implementa nada desta pasta. Uma ideia só vira trabalho quando entra na [ROADMAP](../ROADMAP.md) como fase e ganha o seu plano em [`plans/`](../plans/README.md).

## Como usar
- Uma nota por ideia, criada com o modelo [`_modelos/ideia.md`](../_modelos/ideia.md) (no Obsidian: comando "Inserir modelo").
- O caminho de uma ideia: **crua → madura → virou-fase** (ou **descartada**). O `status` fica no topo da nota.
- A tabela [`ideias.base`](ideias.base) lista todas por status, versão (V1 a V6) e custo (P, M, G).
- A seção "Menor versão que já dá para testar" é a mais importante: ela segura o tamanho da ideia antes de virar fase.
